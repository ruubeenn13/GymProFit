# Trusted sources — Android design

## PRIMARY
- https://developer.android.com/design/ui — Android design hub (mobile, desktop, Wear, TV, cars, XR, AI glasses, widgets)
- https://m3.material.io/ — Material 3 and Material 3 Expressive guidelines
- https://developer.android.com/jetpack/androidx/releases/compose-material3 — Compose Material 3 releases
- https://developer.android.com/jetpack/androidx/releases/compose-material3-adaptive — adaptive library releases
- https://github.com/material-components/material-components-android/releases — MDC-Android (Views) releases
- https://developer.android.com/about/versions — Android version pages and behavior changes
- https://developer.android.com/docs/quality-guidelines — quality checklists (core, adaptive, Wear, TV, car, XR, widgets)
- https://developer.android.com/google/play/vitals — Android vitals thresholds
- https://android-developers.googleblog.com/ — Android Developers Blog
- https://developer.android.com/topic/architecture — app architecture guide

## SECONDARY
- https://design.google/library — Google Design articles (research write-ups)
- Search topic: "Material 3 Expressive update <current year>", "Android <next version> behavior changes"
